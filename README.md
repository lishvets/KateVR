# KAT Loco — VR Locomotion System Landing Page

[Visit the Website](https://lishvets.github.io/KateVR) | [View Figma Design](https://www.figma.com/design/Blpg4iapsI7fRqJeSp6DvK/KatVR-_FE-students?node-id=1-370&t=SqkO06EraVp0cdoq-0)

An immersive and interactive landing page showcasing KAT Loco — an advanced wearable VR locomotion system. The platform highlights key features, hardware specifications, multi-industry applications, interactive help drawers, and direct ordering capabilities.

## Technical Snapshot

- **Core Stack:** HTML5, SCSS (Sass), JavaScript (ES6+)
- **CSS Architecture:** Strictly organized BEM methodology
- **Engineering Standards:**
  - Fully semantic, accessible, and structured HTML markup
  - High-definition responsive image rendering and scalable SVG icon systems
  - Optimized cross-browser CSS reset rules and smooth animations
  - True Mobile-First approach with progressive enhancement for larger viewports

## Key Technical Features

- **Multi-Level Side Navigation:** Includes responsive slide-out drawers for main site navigation, language selection, FAQ, and customer support.
- **Accordion FAQ Component:** Interactive HTML/CSS accordion interface for seamless user experience without cluttering the screen.
- **Custom Media & Showcase Components:** Embedded video triggers, product slider, and responsive specs grid with visual alignment markers.
- **Cross-Platform Compatibility Showcase:** Designed layout for presenting complex hardware details (sensors, battery life, connectivity).
- **Interactive Lead Capture:** Custom-styled contact forms with form-reset handlers and smooth viewport scroll controls.

## Section Highlights
- **Hero Banner:** Dynamic value proposition with fixed CTA order triggers and direct video preview.
- **Beyond Gaming:** Custom grid layout illustrating applications in Education, Real Estate, Fitness, and Social VR.
- **Interactive Tech Specs:** Desktop and mobile responsive displays outlining sensory capabilities, battery metrics, and Bluetooth features.
- **Comprehensive Help Center:** Dedicated drawer sidebars containing instant answers, manuals, and policy documentation.
